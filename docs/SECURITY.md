# Security model

This is for one trusted local owner on a trusted machine. It is not designed as a shared public SaaS. The AI client receives only an API credential, and the human keeps a distinct owner credential. Both must be random, at least 32 characters, and unequal. The owner UI stores the entered key only in tab memory, never cookies/localStorage. Anyone who can read `.env` or administer your machine has owner privileges; server-side separation cannot protect against a compromised host.

Google credentials are obtained using the official authorization code flow, state + browser-binding cookie + PKCE. State is encrypted, expires in ten minutes and is consumed once. Read features request `youtube.readonly`; write consent upgrades to `youtube.force-ssl` (a broad Google scope; no narrower playlist-only scope is claimed). Refreshes occur near access-token expiry. Invalid grants require reauthorization. App secrets are loaded from local environment/.env rather than code.

Tokens, personal metadata cache, OAuth state and drafts are encrypted with Fernet authenticated encryption in SQLite. Database file mode is 0600 on POSIX; Windows filesystem access follows your OS ACLs. Bootstrap creates .env with exclusive creation and POSIX 0600. SQLite keys and quota counters are metadata, not personal token payloads. Back up the encryption key privately; losing it means losing access to retained encrypted records. Records expire, and expired values are purged on startup or accessed/overwritten. Disconnect revokes Google and removes tokens, cache and drafts. SQLite deletion does not promise forensic erasure; protect full-disk storage/backups.

Titles/descriptions/tags are untrusted data. They are never run, interpolated into SQL or placed in owner-page innerHTML. The UI uses textContent and constructed safe YouTube links. MCP exposes no confirmation/create/resume tool. The agent skill explicitly rejects metadata instructions. The server requires an independent owner credential and exact confirmation string for the immutable draft. Human review cannot be replaced by a boolean supplied by a model. JSON transport cannot guarantee a third-party AI client displays metadata safely; install/use trusted clients.

Quota reservations are transactionally checked before workflow calls; attempted calls including failures are charged. Cache hits are free. Daily rollover is Pacific midnight. Crashes retain reserved usage conservatively. If other software consumes the Google project quota, lower this app's allocation. Local rate limits, upstream error normalization and input validation reduce accidental misuse, but are not a substitute for public-hosting defenses.

Owner writes require an Authorization header; CORS is disabled and cross-origin browser writes are rejected. CSP, frame denial, nosniff and no-referrer headers apply. Bind only to loopback by default. HTTPS and a private access layer are required before any public deployment. OAuth callback requires unguessable state and browser cookie. HTTP access logging is disabled by the supplied entry point/container to avoid logging callback codes or metadata queries. Do not enable debug logs for httpx/MCP in live mode; protocol logging can contain user content. No credentials are in included fixtures.

Uncertain remote writes never auto-retry. Inspect your account for a possible empty/partial playlist after a timeout/crash. The app does not delete remote playlists or silently relax constraints. Report security problems privately to your project maintainer; do not include tokens or real user data in reports.

For this private handoff, the user explicitly requested the configured `.env` inside the ZIP. Git excludes it; that does not protect the ZIP itself. No source file, fixture or test report contains the supplied credential values. The application uses the Google API key directly for permitted public reads and never as an OAuth/write fallback.
